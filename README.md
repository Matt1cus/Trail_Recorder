This is a internet/offline cli-based Hike Tracker. 
It utilizes the free Open-Meteo for obtaining local weather online. 

These are the options when running the python script:

Trail Recorder
1. Add a hike
2. List all hikes
3. Stats
4. Monthly Trends
5. Personal Records
6. Quit
